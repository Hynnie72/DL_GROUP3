\## About This Repository



This repository contains the assignments, practical exercises, experiments, and coursework completed by \*\*Group 3\*\* as part of the Deep Learning course.



The project covers several fundamental areas of Deep Learning, including neural network implementation, Convolutional Neural Networks (CNNs), Transfer Learning, Natural Language Processing (NLP), and Medical Image Regression.



Each assignment is organized into a separate Git branch to maintain a clear structure and independent development history.



\## Repository Contents



\### 1. Presentation – CNN Architectures



\*\*Branch:\*\* `presentation-CNN`



This assignment focuses on exploring and implementing different deep learning models based on Convolutional Neural Network (CNN) architectures.



Topics include:

\- Introduction to CNN architecture.

\- Implementation of different CNN models.

\- Model training and evaluation.

\- Comparison of model performance.



\### 2. Lab 1 – Multi-Layer Perceptron (MLP)



\*\*Branch:\*\* `Lab1`



This lab focuses on implementing Multi-Layer Perceptron (MLP) models and understanding the impact of hyperparameters on neural network performance.



The group conducted \*\*15 experiments\*\* to investigate the effects of different hyperparameter configurations.



Key topics:

\- MLP architecture implementation.

\- Hyperparameter tuning.

\- Experimenting with learning rates, batch sizes, network structures, and other configurations.

\- Comparing training performance across experiments.



\### 3. Lab 2 – Transfer Learning with Pretrained CNNs



\*\*Branch:\*\* `Lab2`



This lab explores Transfer Learning techniques using pretrained Convolutional Neural Networks.



The main objective is to understand how pretrained models can be adapted to new image classification tasks.



Key topics:

\- Introduction to Transfer Learning.

\- Using pretrained CNN architectures.

\- Feature extraction and fine-tuning.

\- Model training and performance evaluation.



\### 4. Lab 3 – NLP with Hugging Face Transformers



\*\*Branch:\*\* `Lab3`



This lab focuses on exploring and applying the \*\*Hugging Face Transformers ecosystem\*\* to a practical Natural Language Processing (NLP) task.



The selected task is \*\*Binary Sentiment Analysis\*\*, which classifies text into two categories:



\- `POSITIVE`: Positive sentiment.

\- `NEGATIVE`: Negative sentiment.



Key topics:

\- Introduction to the Hugging Face ecosystem.

\- Working with pretrained Transformer models.

\- Tokenization and text preprocessing.

\- Fine-tuning models for sentiment classification.

\- Model evaluation and prediction.



\### 5. Coursework – Medical Image Regression



\*\*Branch:\*\* `CourseWork`



\*\*Topic:\*\* Medical Image Regression – Age or Tumor Size Prediction



This coursework focuses on applying Deep Learning techniques to medical image regression using the \*\*NIH ChestX-ray14 dataset\*\*.



The objective is to predict a continuous numerical value, such as patient age or tumor size, directly from medical images.



\*\*Task Overview:\*\*



| Component | Description |

|---|---|

| Dataset | NIH ChestX-ray14 |

| Task Type | Regression |

| Model | CNN-based architecture |

| Feature Aggregation | Global Average Pooling |

| Output Layer | Linear Regression Head |

| Target | Continuous numerical value |



\*\*Extensions and Experiments:\*\*

\- Compare MAE and MSE loss functions.

\- Experiment with different data augmentation techniques.

\- Evaluate regression performance using appropriate metrics.
